# Net Worth Snapshot

> Assets minus what you owe, on one clean sheet.

**Live demo:** https://0xelitesystem.github.io/net-worth-snapshot/

Not financial advice. This is an estimate from the numbers you enter, for learning and planning only.

Single HTML file. Runs in the browser with no build step, no server, no tracking, and no data leaving the page.

## What it does

- Totals assets and liabilities across common categories you can edit
- Shows net worth as assets minus total owed, positive or negative
- Draws proportional bars so the balance between the two sides is clear
- Recomputes live as you change any figure

## What it is not

- Not financial advice. A point-in-time estimate from the figures you enter
- Not a tracker. Nothing is saved between sessions, by design

## Use it

Open the hosted page: https://0xelitesystem.github.io/net-worth-snapshot/

Or download `index.html` and open it in any browser. It works offline.

## Privacy

Everything runs client-side. No analytics, no cookies, no network calls, no local storage.
